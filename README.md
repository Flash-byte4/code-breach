# CODE BREACH

Hacker temalı, üs kurma ve strateji oyunu. Ağını kur, savunmanı güçlendir, hedeflerin tüm giriş noktalarına aynı anda saldır.

**Sürüm:** v3.1 (deneme sürümü) · **Platform:** Windows 10/11 (64-bit)

## İndir

👉 [En son sürümü indir (Releases)](https://github.com/Flash-byte4/code-breach/releases/latest)

1. `CODE-BREACH-v3.1-Windows.zip` dosyasını indirin ve bir klasöre çıkarın.
2. `CodeBreach-win32-x64\CodeBreach.exe` dosyasını çalıştırın.
3. Windows SmartScreen uyarı verirse **Ek bilgi → Yine de çalıştır** seçin (oyun imzasız olduğu için normaldir).

Hata ve eksik bildirimleri için [Issues](https://github.com/Flash-byte4/code-breach/issues) bölümünü kullanabilirsiniz.
